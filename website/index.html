Theoria is an open-source Android gallery for the media you already have. Browse by date, search your library, organise albums and favourites, then open a file when you need more than its thumbnail.

Keep some things private

Private folders, vault storage, encrypted media, and backup-related tools are part of the project. They are beta features, not an independent security audit.

Support for panoramas, motion photos, and additional formats depends on Android, bundled codecs, the media file, and the device.

Read the build settings ↗
Photos and videos
Android media access lets the gallery find and manage items on the device.
All Files Access
The default source setting enables the broad MANAGE_EXTERNAL_STORAGE permission. The Play flavour disables it.
Network access
The offline build removes selected network permissions. Network providers are optional build features when offline mode is disabled.

Read this before using an online build

Non-Play release and staging builds currently accept any TLS certificate and hostname. The published offline beta does not include those network-provider paths. Review a custom online build before connecting accounts or credentials.

Download the APK ↗ Check the release notes

  1. Check your device.

    Use an ARM64 Android phone or tablet running Android 10 or later. This is a development beta; keep a separate backup of important media.

  2. Install the APK.

    Download the release shown here and open it from Downloads. If Android asks, allow the browser or file manager you used to install apps, then return to the APK and continue.

  3. Finish first-run setup.

    Grant photo and video access so Theoria can show your library. Review optional requests individually. All Files Access is broad and separate; enable it only if you need features that ask for it.

  4. Confirm your library appears.

    After setup, your device media should appear in the gallery. Try Search suggestions such as Screenshots or Videos, or browse by date.

  5. Fix a missing library, then explore.

    If the gallery is empty, check Theoria’s photo and video permission in Android Settings and confirm the files appear in another gallery app. For install problems, confirm Android 10+ and ARM64. Then read the build notes or report your device, Android version, and symptom in Issues.

Read the source and build notes.

The Android app is written in Kotlin with Jetpack Compose. Within :app, shared foundations live in core, gallery features in feature_node, and provider code in cloud. Bundled models are assembled from :ml-models; included libraries provide gesture, crop, panorama, and scrollbar components.

Build a local copy

Use JDK 17 and the Android SDK and NDK versions declared by the repository. These Gradle tasks compile, test, and assemble the no-ML universal variant:

./gradlew :app:compileUniversalNoMLDebugKotlin
./gradlew :app:testUniversalNoMLDebugUnitTest
./gradlew :app:assembleUniversalNoMLRelease

The APK is written under app/build/outputs/apk/universalNoML/release/. Verify its signing certificate before distributing a local build.

Choose build features

app.properties controls offline mode, All Files Access, maps, and optional Immich, ownCloud, Nextcloud, WebDAV, SMB, and NFS providers. The current source configuration sets OFFLINE=true and ALL_FILES_ACCESS=true; provider flags do not add network access while offline mode is enabled.

The NoML flavor omits bundled model assets. Turning on network providers changes the app’s access needs; review the build and TLS behavior before connecting accounts or credentials.

Before you install.

Check the published file, permissions, and project status that apply to your device.

Is Theoria stable?

No. Version 0.0.1-beta-1 is the first public development beta. Keep a separate backup of important media and expect features to change.

Does the published beta connect to a server?

The current APK is an offline build. Other source configurations can include network providers or maps, so check the exact artifact and its permissions.

Are the vault and encrypted-media features audited?

No independent security audit is documented. Treat these as beta features and do not rely on them as the only copy of important files.

Which devices can install the current APK?

The listed package targets ARM64 devices running Android 10 or newer. The repository has other ABI build options, but the current release page does not list a 32-bit package.
