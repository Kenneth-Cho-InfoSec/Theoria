02 / Be clear about access

Local first.
Configuration matters.

The default project configuration and first published beta are offline builds. Other build configurations can add maps and network providers, so the app’s behavior depends on the variant you install.

Read the build switches ↗
ACCESS, EXPLAINED02—04
A
Photos & videos

Android media access is needed to show and manage your library.

↗
B
All Files Access

The default source setting enables the broad MANAGE_EXTERNAL_STORAGE permission. The Play flavor disables it.

!
C
Network access

The offline build strips selected network permissions. Network providers are optional build features when offline mode is disabled.

↗

Network-build caveat. Non-Play release and staging builds currently trust all TLS certificates and hostnames. The published offline beta does not include network provider paths; inspect a custom online build before connecting accounts or credentials.

Check the release and its permissions before installing. Settings describe the repository defaults; a different build may behave differently.

A few useful details

Before you install.

Is Theoria stable?

No. The current version is the first public beta, `0.0.1-beta-1`. Treat it as development software and keep a separate backup of important media.

Does Theoria always work offline?

The published beta is an offline build, and the repository's default configuration sets `OFFLINE=true`. Other build configurations can enable network providers or maps, so check which variant you are installing.

Does the vault guarantee that files are secure?

The project includes private-folder, vault, encrypted-media, and backup-related functionality. These are beta features; their security properties have not been independently audited.

Can I use the latest beta on a 32-bit phone?

The currently published APK is built for ARM64. The source has other ABI flavors, but a 32-bit release package is not listed on the current release page.
